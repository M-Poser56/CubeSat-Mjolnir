# CubeSat-Mjolnir
Repository for the Mjolnir CubeSat personal project, tracking all code and design material.

The Mjolnir CubeSat is a 10cm by 10cm by 10cm (1U) microsatellite complete with an onboard flight computer, sensor telemetry, radio module, a camera module, custom onboard BMS, onboard attitude control via reaction wheels and custom motor control PCB.

There is also a fully custom groundstation consisting of a python backend and JS frontend, meant to interface with an Arduino Uno running a script to interface with a matching LoRa radio module to the CubeSat.

Had a blast making this, design doc covers everything and is worth a read!
